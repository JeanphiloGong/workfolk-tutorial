# viewer/V0 · 从观察到玩家指令

玩家打开工作台查看活动。播放、单步和重置只移动回放位置。实时视图中，玩家选择一个 Agent 发消息，看到等待确认、接受或拒绝。暂停与改派在 World 确认生效后才更新状态，迟到的响应不得盖过更新的 revision。

运行时拥有共享状态、事件与 [本地 HTTP 契约草案](../../../contracts/viewer.md)。浏览器拥有输入草稿、请求反馈和回放位置。已有原型的能力见 [章节草稿](../v1/replay-viewer.md)。具体命令负载、暂停与改派的生效时点以及拒绝返回结构待在 V0 中定稿。验收在真实浏览器连接本地 World 完成。[V1 实施计划](../v1/plan.md)

成果编辑与多人部署留待后续专题版本设计。
